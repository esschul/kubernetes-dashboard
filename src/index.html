Help & Setup

Required tools

This app shells out to three CLI tools. All must be installed and authenticated before the app can fetch data.

kubectl — Kubernetes CLI
Used to fetch deployments, namespaces and pod status from your cluster.
brew install kubectl
Verify your contexts are set up: kubectl config get-contexts
gh — GitHub CLI
Used to fetch pull requests and CI check status from GitHub.
brew install gh
gh auth login
az — Azure CLI
Used to fetch pipeline runs and build logs from Azure DevOps. Also requires the Azure DevOps extension.
brew install azure-cli
az extension add --name azure-devops
az login
Settings reference
FieldDescription
kubectl contextWhich cluster to connect to. Defaults to your current context.
NamespaceYour team's Kubernetes namespace. Used to scope deployments and as a default GitHub topic.
GitHub OrgYour GitHub organisation name, e.g. my-org.
Repo topicGitHub topic tag shared by your team's repos. Defaults to the namespace name if left blank.

Azure DevOps Org URLYour Azure DevOps organisation URL, e.g. https://dev.azure.com/my-org.
Azure DevOps ProjectThe project name inside your Azure organisation.
Pipeline teamThe Azure DevOps folder your team's pipelines live in (e.g. checkout). Falls back to your namespace if left blank. If a pipeline doesn't show up, go to Azure DevOps → Pipelines → ⋯ → Move and place it in your team's folder.
Datadog Site URLYour Datadog site, e.g. https://app.datadoghq.eu. Used to generate log links on deployment cards.
Environment shortcutsMap Prod / QA / Test to specific kubectl contexts for quick switching.
GitHub repo topics

The Pull Requests view fetches PRs from all repos in your GitHub org that are tagged with your team's topic. To tag a repo, go to the repo on GitHub → About (gear icon) → Topics → add your topic name.

Watched repos & labels

For shared repos (e.g. an IaC or platform repo used by multiple teams), add the repo name under Watched repos in Settings. The app will only show PRs from those repos that have a GitHub label matching your namespace name. Ask the repo owner to add the label to relevant PRs.

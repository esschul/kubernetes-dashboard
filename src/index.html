Help & Setup

Required tools

This app shells out to three CLI tools. All must be installed and authenticated before the app can fetch data.

kubectl — Kubernetes CLI
Used to fetch deployments, namespaces and pod status from your cluster.
brew install kubectl
Verify your contexts are set up: kubectl config get-contexts
gh — GitHub CLI
Used to fetch pull requests and CI check status from GitHub.
brew install gh
gh auth login
az — Azure CLI
Used to fetch pipeline runs and build logs from Azure DevOps. Also requires the Azure DevOps extension.
brew install azure-cli
az extension add --name azure-devops
az login

GitHub repo topics

The Pull Requests view fetches PRs from all repos in your GitHub org tagged with each team's topic. To tag a repo, go to the repo on GitHub → About (gear icon) → Topics → add your topic name. If you're on multiple teams, add yourself to all of them and PRs from all teams will be merged into one list.

Restart deployment?

This uses kubectl rollout restart which does a rolling restart — new pods are started before old ones are terminated. No downtime assuming the deployment has multiple replicas and readiness probes configured.

Roll back deployment?

This uses kubectl rollout undo to restore the pod template to this revision. It does not roll back ConfigMaps, Services, Ingresses, or other Kubernetes resources that may have changed in the same release.
